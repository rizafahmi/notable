# Notable

Notable is a platform for sending feedback, suggestions, and tips directly to creators.

## Public Pages
- [Kirim Feedback & Tips](https://feedback.rizafahmi.com/) - The main landing page for viewers and donors to submit free feedback and optional tips via dynamic QRIS.
- [OBS Overlay](https://feedback.rizafahmi.com/overlay) - OBS stream overlay page for displaying live alerts and emoji reactions.
- [QR Code](https://feedback.rizafahmi.com/qr) - Static QR code page pointing to the main feedback URL for display during streams.
- [Tanya Jawab](https://feedback.rizafahmi.com/questions) - Public audience Q&A board for submitting questions and upvoting what Riza should answer next.
- [QR Code & Feedback Overlay](https://feedback.rizafahmi.com/qr-overlay) - OBS stream page combining the QR code and live emoji feedback reactions on one screen.
- [Suara Ruangan](https://feedback.rizafahmi.com/cloud) - Closing-slide word cloud built from audience feedback for projector or screen share.
- [Suara Ruangan Overlay](https://feedback.rizafahmi.com/cloud-overlay) - Transparent OBS browser source of the same feedback word cloud.
